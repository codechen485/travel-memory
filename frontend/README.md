# 行囊 - 前端项目

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 确保后端已启动

在另一个终端窗口中：

```bash
cd ../backend
npm run start:dev
```

### 3. 启动前端开发服务器

```bash
npm run dev
```

访问：**http://localhost:5173**

## 📁 项目结构

```
src/
├── api/              # API 接口层
│   ├── request.ts    # axios 配置
│   └── auth.ts       # 认证接口
├── assets/           # 静态资源
── router/           # 路由配置
│   └── index.ts
├── stores/           # Pinia 状态管理
│   └── user.ts       # 用户状态
├── views/            # 页面组件
│   ├── Login.vue     # 登录页
│   ├── Register.vue  # 注册页
│   ── Home.vue      # 首页
├── App.vue           # 根组件
└── main.ts           # 入口文件
```

## 🔧 技术栈

- **框架**: Vue 3 + TypeScript
- **构建工具**: Vite
- **UI 库**: Naive UI
- **样式**: Tailwind CSS
- **状态管理**: Pinia
- **路由**: Vue Router
- **HTTP 客户端**: Axios

## ️ 常见问题

### Q: 登录后又跳回登录页？

A: 检查后端是否正常运行，访问 http://localhost:3000/api/health 确认

### Q: 跨域错误？

A: 后端已配置 CORS，检查后端是否正确启动

### Q: Token 失效？

A: 默认有效期 24 小时，重新登录即可
