> - 英文：*Identified naive-ui full-registration as the first-screen bottleneck via Vite bundle analysis; switched to on-demand auto-import with unplugin-vue-components, cutting first-screen JS by ~42% (1454KB→839KB; gzip 405KB→241KB).*
> - 配套可写：*基于 rollupOptions.manualChunks 按「使用范围」拆分 echarts/wangEditor/naive-ui 等大包，配合路由级动态 import 与图片懒加载，单页首屏仅加载必要 chunk。*

### 30. 长列表「加载更多」分批渲染（第五阶段补充）

- [x] **问题**：「我的旅程」「我的文案集」原先一次性 `v-for` 渲染后端返回的全部数据，条目一多页面会无限延伸、DOM 节点暴涨、滚动变卡
- [x] **澄清**：图片 `loading="lazy"` 只延迟屏外图片下载（省流量），**不减少 DOM 节点数**，解决不了「页面越来越长」——需前端切片分批渲染
- [x] **方案**（`JourneyList.vue` / `CopywritingList.vue`）：`PAGE_SIZE=12` + `visibleCount` ref + `computed` 切片（`list.slice(0, visibleCount)`）；列表底部「加载更多（还有 N 段/条）」按钮点击 `visibleCount += PAGE_SIZE`；数据重新拉取时 `visibleCount` 复位；条目 ≤12 时按钮自动隐藏（`v-if="list.length > visibleCount"`）
- [x] **灵感漂流**：已有后端分页「加载更多」（第 11 节），无需改

## 🔌 API 对接说明

### 后端接口地址

- 开发环境：`http://localhost:3000/api`（NestJS 默认端口 3000）
- 生产环境：需修改 `.env.production`

### 已对接的接口

#### 1. 用户注册

- **路径**: POST `/api/auth/register`
- **参数**:
  ```typescript
  {
    username: string // 3-50字符
    email: string // 邮箱格式
    password: string // 至少6字符
  }
  ```
- **返回**:
  ```typescript
  {
    code: 200
    message: '注册成功'
    data: {
      token: string
      userId: number
      username: string
      email: string
      avatar: string | null
    }
  }
  ```

#### 2. 用户登录

- **路径**: POST `/api/auth/login`
- **参数**: `{ username: string, password: string }`
- **返回**: 同注册接口

#### 3. 旅程列表

- **路径**: GET `/api/journeys`
- **返回**:
  ```typescript
  {
    code: 200
    message: '获取成功'
    data: Journey[] // 含 _count: { diaries, photos }
  }
  ```

#### 4. 旅程详情

- **路径**: GET `/api/journeys/{id}`
- **返回**: `JourneyDetail`（含 diaries 日记数组）

#### 5. 创建旅程

- **路径**: POST `/api/journeys`
- **参数**:
  ```typescript
  {
    title: string          // 2-50 字符
    destinations: string[] // 至少一个目的地
    startDate: string      // yyyy-MM-dd
    endDate: string        // yyyy-MM-dd
    coverImage?: string | null
    tags?: string[]
  }
  ```

#### 6. 更新/删除/封存旅程

- PUT `/api/journeys/{id}`、DELETE `/api/journeys/{id}`、POST `/api/journeys/{id}/archive`

> ✅ 后端旅程接口已实现并完成联调测试（创建/列表/详情/更新/删除/封存全部通过），前端可直接对接使用。

## ️ 常见问题

### 跨域错误

后端 NestJS 需配置 CORS：`app.enableCors({ origin: 'http://localhost:5173' })`

### API 请求失败

1. 检查后端是否启动：访问 http://localhost:3000/api/health
2. 检查 `.env.development` 中 API 地址
3. 浏览器 DevTools → Network 查看请求详情

### Token 无效

重新登录获取新 token（默认有效期 24 小时）

### Naive UI 样式不生效

1. 检查 `App.vue` 中是否包裹了 `<n-config-provider>`
2. 本项目已改用 `unplugin-vue-components` + `NaiveUiResolver` **按需自动引入**（不再 `app.use(naive)`）；若组件不识别，先跑一次 `npx vite build` 或 `npm run dev` 让插件生成 `src/components.d.ts`
3. 重启开发服务器
