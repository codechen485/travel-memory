### 启动顺序

```bash
# 1. 先启动后端服务（NestJS）
cd ../backend
npm run start:dev

# 2. 再启动前端
cd ../frontend
npm run dev
```

### 开发端口

- 前端：**5173** (http://localhost:5173)
- 后端：**3000** (http://localhost:3000)

### 测试账号

- 需要先通过注册页面创建用户
- 或使用已注册的测试账号

### Token 管理

- 登录后自动保存到 `localStorage.token`
- 每次请求自动添加 `Authorization: Bearer {token}`
- 有效期：24 小时
- 401 错误自动清除 token 并跳转登录页

## 🔌 API 对接说明

### 后端接口地址

- 开发环境：`http://localhost:3000/api`（NestJS 默认端口 3000）
- 生产环境：需修改 `.env.production`

### 已对接的接口

#### 1. 用户注册

- **路径**: POST `/api/auth/register`
- **参数**:
  ```typescript
  {
    username: string // 3-50字符
    email: string // 邮箱格式
    password: string // 至少6字符
  }
  ```
- **返回**:
  ```typescript
  {
    code: 200
    message: '注册成功'
    data: {
      token: string
      userId: number
      username: string
      email: string
      avatar: string | null
    }
  }
  ```

#### 2. 用户登录

- **路径**: POST `/api/auth/login`
- **参数**: `{ username: string, password: string }`
- **返回**: 同注册接口

#### 3. 旅程列表

- **路径**: GET `/api/journeys`
- **返回**:
  ```typescript
  {
    code: 200
    message: '获取成功'
    data: Journey[] // 含 _count: { diaries, photos }
  }
  ```

#### 4. 旅程详情

- **路径**: GET `/api/journeys/{id}`
- **返回**: `JourneyDetail`（含 diaries 日记数组）

#### 5. 创建旅程

- **路径**: POST `/api/journeys`
- **参数**:
  ```typescript
  {
    title: string          // 2-50 字符
    destinations: string[] // 至少一个目的地
    startDate: string      // yyyy-MM-dd
    endDate: string        // yyyy-MM-dd
    coverImage?: string | null
    tags?: string[]
  }
  ```

#### 6. 更新/删除/封存旅程

- PUT `/api/journeys/{id}`、DELETE `/api/journeys/{id}`、POST `/api/journeys/{id}/archive`

> ✅ 后端旅程接口已实现并完成联调测试（创建/列表/详情/更新/删除/封存全部通过），前端可直接对接使用。

## ️ 常见问题

### 跨域错误

后端 NestJS 需配置 CORS：`app.enableCors({ origin: 'http://localhost:5173' })`

### API 请求失败

1. 检查后端是否启动：访问 http://localhost:3000/api/health
2. 检查 `.env.development` 中 API 地址
3. 浏览器 DevTools → Network 查看请求详情

### Token 无效

重新登录获取新 token（默认有效期 24 小时）

### Naive UI 样式不生效

1. 检查 `App.vue` 中是否包裹了 `<n-config-provider>`
2. 检查 `main.ts` 中是否注册了 Naive UI
3. 重启开发服务器
