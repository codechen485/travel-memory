#  行囊项目 - 快速启动指南

## 📋 前置要求

- Node.js >= 22.18.0
- Docker Desktop（已安装）

---

## ⚡ 一键启动流程

### 步骤 1：启动后端服务

打开终端（PowerShell 或 CMD），执行：

```bash
cd c:\Web\xingnang\backend-nestjs

# 启动 PostgreSQL 和 Redis
docker-compose up -d

# 同步数据库结构
npx prisma db push

# 启动 NestJS 应用
npm run start:dev
```

**等待看到以下日志表示启动成功：**
```
Application is running on: http://localhost:3000
```

**验证后端是否正常运行：**
访问 http://localhost:3000/api/health  
应该返回：`{"code":200,"message":"服务运行正常","data":null}`

---

### 步骤 2：启动前端服务

打开**另一个终端窗口**，执行：

```bash
cd c:\Web\xingnang\frontend

# 首次运行需要安装依赖
npm install

# 启动开发服务器
npm run dev
```

**等待看到以下日志表示启动成功：**
```
VITE v8.x ready in xxx ms

  Local:   http://localhost:5173/
```

---

### 步骤 3：访问应用

在浏览器中打开：**http://localhost:5173**

你会自动跳转到登录页面。

## ️ 常见问题

### Q1: 前端启动报错 "Port 5173 is already in use"
**解决**：端口被占用，修改 `vite.config.ts` 中的端口，或关闭占用端口的进程

### Q2: 后端启动报错 "Port 3000 is already in use"
**解决**：修改 `src/main.ts` 中的端口号，或关闭占用端口的进程

### Q3: 登录/注册时提示网络错误
**排查**：
1. 检查后端是否启动：访问 http://localhost:3000/api/health
2. 检查 Docker 容器是否运行：`docker ps`
3. 查看浏览器控制台 Network 标签的请求详情

### Q4: 跨域错误（CORS）
**解决**：后端已配置 CORS，检查 `src/main.ts` 中的 `app.enableCors()` 配置

### Q5: Token 失效，频繁跳转登录页
**解决**：
1. 清除浏览器 localStorage
2. 重新登录获取新 token
3. 检查 .env 中的 JWT_SECRET 配置

### Q6: 数据库连接失败
**解决**：
1. 确保 Docker 容器运行：`docker-compose up -d`
2. 检查 .env 中的 DATABASE_URL 配置
3. 运行 `npx prisma db push` 同步表结构

##  小贴士

1. **同时打开两个终端**：一个用于后端，一个用于前端
2. **使用 Postman 测试 API**：比浏览器更方便，参考 [API 测试指南](./API_TEST_GUIDE.md)
3. **查看浏览器控制台**：F12 打开开发者工具，查看 Console 和 Network 标签
4. **热重载**：后端使用 `npm run start:dev` 支持热重载，前端修改代码后会自动刷新
5. **保存进度**：定期提交代码到 Git，避免丢失工作
