## 📝 重要提示

1. **启动顺序**:
   ```bash
   # 1. 先启动 Docker 服务
   docker-compose up -d
   
   # 2. 同步数据库结构
   npx prisma db push
   
   # 3. 再启动 NestJS 应用
   npm run start:dev
   ```

2. **测试账号**:
   - 需要先通过注册接口创建用户
   - 参考 `API_TEST_GUIDE.md` 中的测试用例

3. **JWT Token**:
   - 有效期：24小时
   - 密钥：可在 .env 中修改 `JWT_SECRET`

4. **数据库表**:
   - 使用 Prisma 管理表结构
   - 运行 `npx prisma db push` 同步到 PostgreSQL
